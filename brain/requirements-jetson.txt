# NVIDIA Jetson (Orin Nano, JetPack 6 / Ubuntu 22.04) hardware-control dependencies for the brain.
# Install into a --system-site-packages venv so it also sees JetPack's system OpenCV + GStreamer:
#   python3 -m venv --system-site-packages .venv && .venv/bin/pip install -r requirements-jetson.txt
#
# Differences from the Pi's requirements.txt:
#   - gpiozero + lgpio are DROPPED (Pi-specific GPIO); the Jetson uses Jetson.GPIO (brain/hcsr04_jetson.py).
#   - adafruit-extended-bus is ADDED so ServoKit can bind to the Jetson header's I2C bus (ROBOT_I2C_BUS).
#   - the camera uses system OpenCV (apt python3-opencv) via --system-site-packages, not a pip wheel.
# The AI stack (Ollama, whisper.cpp, Piper, arecord/aplay) is set up by scripts/install_stack_jetson.sh.

adafruit-circuitpython-servokit   # ESC + steering servo via PCA9685 (pulls in Blinka + Jetson.GPIO + PlatformDetect)
adafruit-extended-bus             # bind ServoKit to an arbitrary numbered I2C bus (Jetson header ~ bus 7)
Jetson.GPIO                       # 3x HC-SR04P ultrasonic sensors (front / left / right) -- see hcsr04_jetson.py
Pillow                            # camera frame letterbox/JPEG + procedural/animated face rendering
numpy                             # RGB565 packing for the DSI/HDMI framebuffer face fallback
pyserial                          # USB-C face panel (turing-smart-screen serial protocol)

# --- Wake word (only when ROBOT_WAKEWORD_ENABLE=1; still 100% offline) ---
openwakeword==0.4.0               # PINNED: bundles its feature models in the wheel; installs with onnxruntime
onnxruntime                       # runs the wake-word + feature models on CPU (GPU not needed for the wake word)
sounddevice                       # continuous 16 kHz mic capture for the wake listener (needs PortAudio)
